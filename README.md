# Movie Finder
پروژه Movie Finder یک سایت جستجو و نمایش اطلاعات فیلم است که با استفاده از HTML، CSS و JavaScript خالص پیاده‌سازی شده است.

در این پروژه اطلاعات فیلم‌ها از طریق API دریافت می‌شوند و کاربر می‌تواند فیلم‌ها را مشاهده و جستجو کند، فیلم‌ها را بر اساس ژانر مشاهده کند و وارد صفحه جزئیات هر فیلم شود.


## امکانات
* نمایش لیست فیلم‌ها
* جستجوی فیلم
* نمایش نتایج مرتبط هنگام جستجو
* نمایش نتایج کامل جستجو
* نمایش جزئیات فیلم
* نمایش فیلم‌ها بر اساس ژانر
* اسلایدر فیلم‌ها در صفحه اصلی
* صفحه‌بندی نتایج
* نمایش تصاویر، امتیاز، ژانر و توضیحات فیلم
* طراحی واکنش‌گرا برای اندازه‌های مختلف صفحه


## تکنولوژی‌های استفاده شده
* HTML5
* CSS3
* JavaScript
* Fetch API
* REST API
* CSS Grid
* CSS Flexbox

در این پروژه از هیچ فریم‌ورک فرانت‌اندی مانند React استفاده نشده است.


## API
برای دریافت اطلاعات فیلم‌ها از MoviesAPI.ir استفاده شده است.

اطلاعاتی مانند عنوان فیلم، تصویر، ژانر، امتیاز، سال انتشار و توضیحات از API دریافت می‌شوند.
